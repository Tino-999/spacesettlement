\# SpaceSettlement – DATA\_MODEL



\## Source of Truth

Cloudflare D1 is the source of truth for all items.

External sources and AI outputs are non-authoritative inputs.



\## Table: `items`



\### Primary Key

\- `id` (TEXT, PRIMARY KEY)

&nbsp; - Stable identifier.

&nbsp; - Generated by the backend on create.



\### Core Fields (required)

\- `type` (TEXT, NOT NULL)

&nbsp; - Allowed values:

&nbsp;   - `PROJECT`

&nbsp;   - `FICTION`

&nbsp;   - `CONCEPT`

&nbsp;   - `TOPIC`

&nbsp;   - `ORG`

&nbsp;   - `PERSON`

&nbsp;   - `BOOK`

&nbsp;   - `MOVIE`

\- `title` (TEXT, NOT NULL)

&nbsp; - Human-readable canonical label.

\- `createdAt` (TEXT, NOT NULL)

&nbsp; - ISO 8601 UTC timestamp.



\### Lifecycle Fields (required)

\- `status` (TEXT, NOT NULL)

&nbsp; - Allowed values:

&nbsp;   - `draft`

&nbsp;   - `published`

&nbsp;   - `deleted`

\- `updatedAt` (TEXT, NOT NULL)

&nbsp; - ISO 8601 UTC timestamp.

\- `deletedAt` (TEXT, NULL)

&nbsp; - ISO 8601 UTC timestamp.

&nbsp; - Must be NULL unless `status='deleted'`.



\### Public Display Fields (optional)

\- `href` (TEXT, NULL)

&nbsp; - External reference URL.

\- `imageUrl` (TEXT, NULL)

&nbsp; - Public image URL.

\- `summary` (TEXT, NULL)

&nbsp; - Curated short description.

\- `tags` (TEXT, NULL)

&nbsp; - Flat string list, storage format defined by backend.

&nbsp; - No semantic meaning is implied by ordering.



\### Sorting and Dating Fields (optional)

\- `sortYear` (INTEGER, NULL)

&nbsp; - Primary sorting year for timeline-like ordering.

\- `birthYear` (INTEGER, NULL)

&nbsp; - Only valid for `type='PERSON'`.

\- `deathYear` (INTEGER, NULL)

&nbsp; - Only valid for `type='PERSON'`.



\## Classification Fields



\### `project\_class` (TEXT, NULL)

Valid only for `type='PROJECT'`.



Allowed values (exhaustive):

\- `CLASS I`    Active state-run programs

\- `CLASS II`   Official roadmaps and strategies

\- `CLASS III`  Government studies and architectures

\- `CLASS IV`   Technical system designs by individual actors

\- `CLASS V`    Strategic or civilizational concepts



Constraints:

\- If `type != 'PROJECT'` then `project\_class` MUST be NULL.

\- If `type == 'PROJECT'` then `project\_class` MAY be NULL or one of the allowed values.



\### `fiction\_class` (TEXT, NULL)

Valid only for `type='FICTION'`.



Allowed values (exhaustive):

\- `CLASS A`  Demonstrable influence on real spaceflight or settlement concepts

\- `CLASS B`  Influence on public spaceflight and settlement narratives

\- `CLASS C`  Explorative or philosophical scenarios

\- `CLASS D`  Spaceflight as backdrop without conceptual influence



Constraints:

\- If `type != 'FICTION'` then `fiction\_class` MUST be NULL.

\- If `type == 'FICTION'` then `fiction\_class` MAY be NULL or one of the allowed values.



\### `topics` (TEXT, NULL)

Valid for all types.



Topic hierarchy is semantic only.

Storage is a flat list of strings.

No implicit parent assignment exists.



Allowed values are limited to the following controlled vocabulary (exhaustive).



\- `SETTLEMENT ARCHITECTURES / Generation ships`

\- `SETTLEMENT ARCHITECTURES / Space habitats (rotational)`

\- `SETTLEMENT ARCHITECTURES / Planetary surface settlements`

\- `SETTLEMENT ARCHITECTURES / Subsurface habitats`

\- `SETTLEMENT ARCHITECTURES / Mobile vs. fixed settlements`



\- `LAW / Space treaties and principles`

\- `LAW / Jurisdiction and governance off-Earth`

\- `LAW / Property and resource rights`

\- `LAW / Liability and insurance`

\- `LAW / Labor and crew status`

\- `LAW / Bioethics and medical law`

\- `LAW / Heritage and environmental protection`



\- `RELIGION / Religious practice in confined environments`

\- `RELIGION / Timekeeping and calendars off-Earth`

\- `RELIGION / Dietary rules and life-support constraints`

\- `RELIGION / Rituals, death, and handling of remains`

\- `RELIGION / Chaplaincy and psychological interfaces`

\- `RELIGION / Freedom of religion in settlements`



Constraints:

\- `topics` MAY be NULL.

\- If non-NULL, every element MUST match one allowed value.



\## `meta` Field



\### `meta` (TEXT, NULL)

\- JSON string.

\- Stores enrichment payloads and external identifiers.



Required keys when present:

\- `source` (TEXT)

&nbsp; - Provider name, e.g. `wikidata` or `openlibrary`.

\- `sourceId` (TEXT)

&nbsp; - Provider identifier, e.g. Wikidata Q-ID or Open Library ID.



Recommended keys (optional):

\- `aliases` (array of TEXT)

\- `externalIds` (object)

\- `claims` (object)

\- `descriptionRaw` (TEXT)

\- `images` (array)

\- `lastEnrichedAt` (TEXT, ISO 8601)



Constraints:

\- `meta` MUST NOT be treated as authoritative.

\- `meta` MUST NOT be required for `published` status.

\- `meta` MUST be valid JSON if non-NULL.



\## Visibility Rules (Public API)



\- `status='published'` items are returned by default in public listings.

\- `status='draft'` items are returned only to admin.

\- `status='deleted'` items are never returned publicly.



\## Deletion Rules



\### Soft-Delete

On soft-delete:

\- `status` becomes `deleted`.

\- `deletedAt` is set to now.

\- Item remains stored.



\### Restore

On restore:

\- `status` becomes `draft` unless prior state is stored.

\- `deletedAt` becomes NULL.



\### Purge

On purge:

\- Row is permanently removed from `items`.



\## Validation Summary (Normative)



\- `type` MUST be one canonical type.

\- `project\_class` MUST be NULL unless `type='PROJECT'`.

\- `fiction\_class` MUST be NULL unless `type='FICTION'`.

\- `birthYear` and `deathYear` MUST be NULL unless `type='PERSON'`.

\- `topics` values MUST be from the controlled vocabulary.

\- `deletedAt` MUST be NULL unless `status='deleted'`.
